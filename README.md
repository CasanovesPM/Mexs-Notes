# Mexs Notes

A web-based notes management application with tags and organization features, designed to manage personal or work-related information in a simple and efficient way.

This project focuses on usability, data organization and real user interaction.

## 🚀 Features

- Create, edit and delete notes
- Tag system for better organization
- Search and filtering
- Clean and simple user interface
- Data persistence

## 🧰 Tech Stack

- JavaScript
- React
- Firebase / Firestore

## 🧪 Purpose

This project is used as:

- A real usage application
- A functional testing environment
- A UI/UX validation project
- A base for experimenting with data structures and user flows

It helps validate how users interact with information, how data is stored and how the system behaves in real scenarios.
